SLDataAPI

C# / .NET · LabAPI 原生 · 运行于 SCP:SL 服务端

通过 HTTP / WebSocket API 实时暴露服务器状态——在线玩家、回合信息、核弹状态、阵营分布， 给查询工具和控制台当统一数据源。002 是它的群聊查询前端，platform 页写的是配套的自托管控制台。

  • 01多源数据聚合：玩家 / 回合 / 服务器 / 核弹 / 阵营
  • 02HTTP / WebSocket 实时查询接口
  • 03面向 astrbot_plugin_sl_query 的数据推送
  • 04面向 Foundation Console 的服务器控制能力

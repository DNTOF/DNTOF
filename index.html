01 / FEATURED · 重点项目

SLDataAPI 服务端数据接口

SLDataAPI

面向 astrbot_plugin_sl_query 和 FDC 控制台的 EXILED 服务端信息提供与服务器控制插件。 通过 HTTP API 实时暴露服务器状态——在线玩家、回合信息、核弹状态、阵营分布， 为前端查询工具和控制台提供统一的数据源。

  • 多源数据聚合：玩家 / 回合 / 服务器 / 核弹 / 阵营
  • HTTP API 实时查询，低延迟推送
  • 支持 FDC 控制台远程服务器控制

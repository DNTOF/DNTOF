SLDataAPI

一套给 SCP:SL 服主用的服务端工具：跑在游戏服务器里的插件负责数据与控制接口， 配套的 Web 控制台（Foundation Console）负责远程管理。 目前闭源开发中，源码计划 2027 年 1 月 1 日公开。

GitHub ↗ v2.6.0 preview · 2026-09

两个部分

In-game

SLDataAPI

以 LabAPI 原生插件的形式运行在服务器进程里，不依赖 EXILED。 把游戏内的实时状态整理成结构化数据，也接收来自外部的控制操作。

C# WebSocket / HTTP 事件驱动
Self-hosted

Foundation Console

可自托管的 Web 管理控制台：多服务器总览、公告、语音监听、地图控制。 浏览器与游戏服之间的流量全部由平台服务端转发，凭据不下发前端。

React · TypeScript Node.js 自托管

接口说明

数据接口（只读） 玩家、回合、核弹、阵营这类实时状态，HTTP 拉取或 WebSocket 推送，机器人与监控页从这里取数。
控制接口 独立 API Key 鉴权，和只读接口分开；按游戏内 RA 面板的语义分域（moderation / admin / round / map / console…），高频调用走单一长连接。
游戏内举报 玩家在服务器设置面板（SSS）里就能举报违规的人，平台端提供对应的处理端点。
审计日志 侵入性控制操作自动记录时间、端点与结果——不记来源 IP。
语音与地图 控制台可以实时监听语音（Opus 解码转发），也能直接控制门、电梯和灯光。
公告与界面 Markdown 公告、中英双语界面，另带几套主题——包括一个可以放视频背景的。

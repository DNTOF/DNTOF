01 · 架构

两个进程，一端约定，一类优雅。

整个生态由两个可独立部署的部分构成：一个跑在游戏服务器进程内的原生插件， 与一个可自托管的 Web 控制台。两者通过一组清晰、文档化的接口对话。

In-Game · 游戏服侧
SLDataAPI

运行于服务器进程的 LabAPI 原生插件，零 EXILED 依赖。把游戏世界的实时状态 变成结构化数据，把管理员的意图变成可远程调用的控制操作。

LabAPI Native WebSocket / HTTP 事件驱动
Self-hosted · 平台侧
Foundation Console

可自托管的 Web 管理控制台：多服务器总览、实时控制、日志、地图、语音—— 浏览器与游戏服之间所有流量由平台服务端承载，凭据永不下发前端。

React · TypeScript Node.js 自托管
一次握手，双向语义
02 · 能力版图

从源码里长出来的能力，而不是功能清单。

SLDataAPI · Control
控制接口 WebSocket 化

控制接口为版本化分域契约（按 RA 面板语义组织），高频调用走单一长连接（hello / call / result 信封）；鉴权双轨、写操作留痕。

SLDataAPI · Events
实时事件流推送

服务器侧状态事件主动推送，而非轮询拉取——玩家进出、回合切换、设施变化，毫秒级抵达。

SLDataAPI · Player
游戏内举报（SSS 面板）

玩家在服务器设置面板即可举报违规者，平台端提供完整处理端点——把社区治理交还给玩家。

SLDataAPI · Audit
控制操作审计日志

侵入性远程操作自动记录：时间、端点、请求、结果——管理出问题时，按时间追责。

Foundation Console · Realtime
多服务器实时总览

一台控制台管理多台服务器：状态聚合、一键切换、所有页面实时联动。

Foundation Console · Media
语音监听与地图控制

WebSocket 实时语音流转发（Opus 解码为 PCM）；地图页面直接控制门、电梯、灯光——与游戏内 RA 面板齐平。

Foundation Console · Comm
公告系统与双语界面

Markdown 公告页 + 登录弹窗 + 版本记忆；中英双语覆盖每一个角落，移动端自适应。

Foundation Console · Themes
主题系统与动态背景

暗色工业 / 亮色 / 二次元三套主题——二次元主题支持视频背景与毛玻璃控件，为不同审美的服主准备。

03 · 安全理念
“一个密码系统应当保持安全——即使敌方知晓除密钥外的一切细节。”
—— Auguste Kerckhoffs · La cryptographie militaire (1883) · 项目代号 Kerckhoffs 的由来

这套生态的安全设计遵循同样的原则：一切可以被公开的，都应公开—— 秘密只存在于应当存在的密钥里。双轨凭证分离只读与写权限；配置缺陷（如引号、特殊字符）在启动时被显式点破， 而不是让管理员在 403 里困惑。 当源码按计划公开后，这份承诺将交由社区共同检验。

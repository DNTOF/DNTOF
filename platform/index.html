SLDataAPI

一套给 SCP:SL 服主用的服务端工具：跑在游戏服务器里的插件负责数据与控制接口， 手机上用 SLConsole 远程管理。原 Web 控制台 Foundation Console（FDC） 已于 2026 年 10 月 25 日停止运行。

FDC 已于 2026-10-25 停止运行。 接替它的是 Android 应用 SLConsole。 FDC 的源码仍会按计划公开，时间见页面底部的倒计时。

SLDataAPI ↗ SLConsole ↗

两个部分

In-game

SLDataAPI

以 LabAPI 原生插件的形式运行在服务器进程里，不依赖 EXILED。 把游戏内的实时状态整理成结构化数据，也接收来自外部的控制操作。

C# WebSocket / HTTP 事件驱动
Android

SLConsole

接替 FDC 的手机端管理应用：实时状态、玩家、地图、远程控制台和插件管理， 全部通过 SLDataAPI 与服务器通信。

Kotlin · Compose Material 3 Android

接口说明

数据接口（只读） 玩家、回合、核弹、阵营这类实时状态，HTTP 拉取或 WebSocket 推送，机器人与监控页从这里取数。
控制接口 独立 API Key 鉴权，和只读接口分开；按游戏内 RA 面板的语义分域（moderation / admin / round / map / console…），高频调用走单一长连接。
游戏内举报 玩家在服务器设置面板（SSS）里就能举报违规的人，平台端提供对应的处理端点。
审计日志 侵入性控制操作自动记录时间、端点与结果——不记来源 IP。
语音与地图 语音经 WebSocket 实时转发（Opus 解码）；门、电梯、灯光可以远程控制。
实时事件流 服务器侧状态事件主动推送——玩家进出、回合切换、设施变化毫秒级抵达，不用轮询。

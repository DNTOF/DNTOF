## About

高中生，开发爱好者，课余时间写代码。个人主页：[dntof.com](https://dntof.com)

我喜欢把日常里觉得别扭的地方做成小工具。最近的重心在 AI 编码工作流：怎么让 AI 助手稳定、安全地驱动本地编码工具。我也做跨平台应用和一些硬件小项目。写到哪学到哪，C# 和 Python 用得最多，最近也在写 TypeScript 和 Rust。

## 最近在折腾

- **AI 编码工作流**：给桌面端编码工具写桥接插件，让 AI 助手可以远程开会话、派任务、查进度，还要处理排队、保活和额度限制。也在给相关的开源编排项目提贡献。
- **跨平台应用**：用 Tauri 做手写数学公式识别，覆盖 Windows、Android 和 iPad。最近在把识别模型从浏览器里的 WebAssembly 搬到原生 Rust 推理，让旧设备也能跑得动。
- **服务端与接口**：写 HTTP / WebSocket 数据接口，以及配套的权限管理和手机端控制台。
- **硬件小项目**：用 51 单片机和 ESP8266 做了一块桌面小屏，把电脑上 AI 任务的进度实时显示出来。

## 正在学

- Agent Client Protocol（ACP）与 MCP 这类 AI 工具协议
- 移动端（Android / iOS）的构建与发布流程
